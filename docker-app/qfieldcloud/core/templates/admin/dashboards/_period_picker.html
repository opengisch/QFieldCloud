{% load i18n %} {% comment %} A button with the selected dashboard time period opens a dropdown that lists every time period. Picking one reloads the page with its key in the `period` parameter. The markup and classes follow Unfold's `unfold/helpers/display_dropdown.html`. Args: periods: the periods to list, a dict from period key to a dict with a `title`, e.g. `DASHBOARD_PERIODS` selected: the key of the selected period, e.g. "30d" selected_title: the title of the selected period, shown on the button, e.g. "Last 30 days" {% endcomment %}
